### Cuboid 参数 (示例)
`setPosition / setOrientation / setName / setWidth / setHeight / setLength / addSurfaceInfo`
Cylinder: `setRadius / setLength / setTaper`
Sphere: `setRadius`
Solid 容器: `ORAGenericSolidObj` 通过 `getCSGTree → restoreRootNode → restoreRegion` 链接到 primitive 或布尔算子。

### 推论
新建 block/cylinder/sphere/toroid 应直接写 CSG 参数化 primitive，**LT 会自行在 ACIS 内核中重建几何**，无需内嵌 SAT、零 SAT 依赖、零风险。仅自由形状 (GenericPrimitive/SAT-导入) 才需要内嵌 SAT。

### ACIS 自研写侧勘察结论
- `cadquery-ocp 7.9.3` 在 `.venv-occ` 里 `OCP.SATControl` 模块**整体缺失**（Reader 与 Writer 都被剔除；非只 Writer），无 SAT 读取可作校验器。
- `pythonocc-core 7.9.3` (conda-forge) 同。
- OCCT 官方开源版不含 ACIS 商业组件，无法自包 wheel；OCP 弃用 ACIS 是 license 原因，不会回退。
- 66 个 SAT 样本全是 sheet/单面 (face=1 居多，37 含 plane，29 含 spline，2 含 ellipse，无 box/cylinder 完整拓扑模板可抄)。
- 自研方向"自洽可行、无第三方校验"，写侧风险集中在 coedge 双向链 + face sense + edge 参数化一致性。
